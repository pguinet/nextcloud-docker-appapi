## Project Overview

Production-ready Docker stack for deploying Nextcloud with AppAPI (ExApps) support. Enables running external applications like Nextcloud Assistant, Context Chat, Recognize, and Whisper Speech-to-Text.

**Language**: Documentation in French, code comments bilingual.

## Architecture

```
┌────────────────────────────────────────────────────────────────┐
│                         Caddy                                   │
│                    (reverse proxy + SSL)                        │
└───────────────────────────┬────────────────────────────────────┘
                            │
┌───────────────────────────▼────────────────────────────────────┐
│                       Nextcloud                                 │
│                       (Apache)                                  │
└─────┬──────────────┬──────────────┬────────────────────────────┘
      │              │              │
┌─────▼─────┐  ┌─────▼─────┐  ┌─────▼─────────────────┐
│ PostgreSQL│  │   Redis   │  │  Docker Socket Proxy  │
└───────────┘  └───────────┘  └─────────┬─────────────┘
                                        │
                              ┌─────────▼─────────────┐
                              │   ExApp Containers    │
                              └───────────────────────┘
```

**Networks**:
- `frontend`: Caddy ↔ Nextcloud only
- `backend`: Internal services (Nextcloud, PostgreSQL, Redis, Docker Proxy, Cron)

## Common Commands

### Stack Management
```bash
# Install (interactive setup)
./scripts/install.sh

# Start/Stop
docker compose up -d
docker compose down

# Logs
docker compose logs -f [service]
docker compose ps
```

### Nextcloud OCC Commands
```bash
docker compose exec -u www-data nextcloud php occ [command]

# Examples
docker compose exec -u www-data nextcloud php occ status
docker compose exec -u www-data nextcloud php occ maintenance:mode --on
docker compose exec -u www-data nextcloud php occ maintenance:mode --off
docker compose exec -u www-data nextcloud php occ db:add-missing-indices
docker compose exec -u www-data nextcloud php occ files:scan --all
```

### Backup/Restore
```bash
./scripts/backup.sh
./scripts/restore.sh /path/to/backup.tar.gz
```

### Update Nextcloud
```bash
./scripts/backup.sh
docker compose pull nextcloud
docker compose up -d
docker compose exec -u www-data nextcloud php occ upgrade
docker compose exec -u www-data nextcloud php occ maintenance:mode --off
```

## AppAPI Configuration

After Nextcloud is running, configure the AppAPI daemon:

1. Go to **Administration → AppAPI → Deploy Daemons**
2. Register with:
   - Name: `docker-local`
   - Deployment method: Docker Socket Proxy
   - Daemon Host: `docker-socket-proxy:2375`
   - HTTPS: Disabled
   - Network: `nextcloud-docker-appapi_backend` (verify with `docker network ls | grep backend`)

## Environment Variables

Key variables in `.env`:
- `NEXTCLOUD_DOMAIN`: Domain for SSL certificate
- `NEXTCLOUD_VERSION`: Nextcloud image tag (default: 30)
- `POSTGRES_PASSWORD`: Database password (auto-generated by install.sh)
- `PHP_MEMORY_LIMIT`: PHP memory (default: 1G)
- `PHP_UPLOAD_LIMIT`: Max upload size (default: 10G)

## Troubleshooting

```bash
# Test Docker Socket Proxy
docker compose exec nextcloud curl http://docker-socket-proxy:2375/version

# Fix permissions
docker compose exec nextcloud chown -R www-data:www-data /var/www/html/data

# Exit maintenance mode
docker compose exec -u www-data nextcloud php occ maintenance:mode --off
```
